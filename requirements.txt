# - The approval *window* (server.py) uses tkinter, which ships with the

#   Linux install it with:  sudo apt-get install python3-tk
# - The optional AI risk agent (risk_agent.py) shells out to the `claude` CLI
#   if it is on PATH; if it is not, TARA falls back to asking a human. No extra
#   Python package is required for it.
